# Related backend (optional / desktop parity)

The **live web app** runs Related on Cloudflare Workers AI — no local server needed.

This folder is only useful if you want the same MiniLM pass on your PC (or offline):

```powershell
python run_once.py ..\input\FOExport.xlsx
```

Or use desktop `similarity.py`. Upload the results workbook to the site if you prefer that path.
